# Command System evaluation

`@tanstack/react-hotkeys@0.12.1` is the selected shortcut runtime: its official React adapter provides lifecycle-managed hooks and the package accepts the repository's React 19 runtime. Base UI `Dialog` 1.8.0 supplies modal focus, escape handling, portal, and focus restoration without introducing a second command primitive. The capability intentionally keeps filtering and command execution application-owned.

The add-on does not include TanStack Virtual because virtualization is outside Command System v1. No server, database, or authorization dependency is required.
