# Command System evaluation

Selected `@tanstack/react-hotkeys@0.12.1` (npm `latest`) and `@base-ui/react@1.8.0`. Official TanStack Hotkeys React hooks provide lifecycle-managed registration and React 19 compatibility. Base UI Dialog supplies modal focus, escape, portal, and restoration behavior. Search, navigation, and authorization remain caller-owned. No virtualization or server dependency is included.
